# DEADZONE — 在线 FPS 射击游戏

**在线游玩：[https://fps.leskur.cn](https://fps.leskur.cn)**

基于 **Three.js + Socket.io** 的第一人称多人联机射击游戏，十字形 CS 风格地图，自由混战模式。

---

## 快速启动（本地）

```bash
# 进入目录
cd fps-online

# 安装依赖（只需一次）
npm install

# 启动服务器
npm start
```

打开浏览器访问 → **http://localhost:3000**

---

## 公网联机方法

### 方法一：frp（推荐，稳定）

1. 下载 [frp](https://github.com/fatedier/frp/releases)
2. 在 `frpc.toml` 配置：
   ```toml
   serverAddr = "你的公网服务器IP"
   serverPort = 7000

   [[proxies]]
   name = "fps"
   type = "tcp"
   localIP = "127.0.0.1"
   localPort = 3000
   remotePort = 3000
   ```
3. 运行 `frpc -c frpc.toml`
4. 朋友访问 `http://你的公网IP:3000`

### 方法二：ngrok（最简单，无需服务器）

```bash
# 安装 ngrok 后
ngrok http 3000
```
ngrok 会给你一个公网 HTTPS 地址，直接分享给朋友即可。

### 方法三：端口映射（路由器）

在路由器管理页面将外网端口 **3000** 映射到本机内网 IP 的 3000 端口，
朋友访问 `http://你的公网IP:3000`。

## 游戏规则

- **自由混战 (FFA)**：打死所有人，击杀 +1 K，被击杀 +1 D
- **弹药**：无限备弹，打空后按 `R` 换弹
- **复活**：死亡 3 秒后随机位置复活，满血复活
- **小地图**：右下角显示己方（黄色）和其他玩家（蓝色）位置及朝向
- **排行榜**：左上角实时显示所有玩家 K/D

## 技术架构

```
fps-online/
├── server.js          # Node.js 服务端（Express + Socket.io）
│                        - 玩家管理、位置同步转发
│                        - 服务端射线检测（防作弊）
│                        - 死亡/复活逻辑
│                        - 2秒广播排行榜
├── public/
│   └── index.html     # 单文件客户端
│                        - Three.js 3D 渲染
│                        - Pointer Lock 鼠标控制
│                        - 位置插值平滑（20Hz同步）
│                        - 子弹轨迹/血液粒子特效
│                        - Web Audio 枪声
└── package.json
```

### 同步策略
- 客户端以 **20Hz** 发送位置/旋转数据给服务端
- 服务端直接转发给其他客户端（权威性在射击判定上）
- 客户端做 **线性插值** 平滑其他玩家移动
- **射击判定在服务端**（射线检测），防止基本作弊
